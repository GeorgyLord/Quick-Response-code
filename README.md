# 🤖 Quick-Response-code

**Quick-Response-code** — это легковесное, модульное консольное приложение на Python для двусторонней работы с QR-кодами: от умной генерации дизайнерских векторов до отказоустойчивого сканирования растровых изображений через системный графический интерфейс.

## 📋 Описание проекта

Проект спроектирован по современным стандартам разработки (PEP 621, PEP 484) и представляет собой утилиту с удобным интерактивным CLI-меню. Архитектура приложения строго разделена на независимые слои (генерация, сканирование и интерфейс взаимодействия), что позволяет легко масштабировать проект или интегрировать его логику в веб-сервисы и Telegram-ботов.

### 🌟 Ключевые инженерные решения:
- **Умная кастомизация (Генерация):** В отличие от стандартных решений, проект создает QR-коды с максимальным уровнем избыточности (`Error Correction Level: H`). Это позволяет коду оставаться читаемым даже при повреждении или перекрытии до 30% его площади (например, при наложении логотипа).
- **Отказоустойчивое распознавание (Сканирование):** Модуль сканирования оснащен алгоритмом предварительной обработки изображений. Он автоматически убирает прозрачность (альфа-каналы) из PNG-файлов, заменяя её подложкой, и динамически изменяет размер изображения методом сглаживания `LANCZOS`, если первичный анализ не дал результатов. Это повышает точность распознавания «замыленных» кодов.
- **Native UI (Интеграция с ОС):** Программа бережно относится к ресурсам компьютера. Вместо запуска тяжелых графических движков (вроде Tkinter) для выбора файлов используется прямой вызов нативного проводника операционной системы с аппаратной поддержкой высокого разрешения (DPI Awareness), что исключает размытие интерфейса на 2K/4K мониторах.
- **Современный менеджмент зависимостей:** Проект полностью переведен на декларативный формат конфигурации `pyproject.toml`, избавляя от устаревших файлов `requirements.txt` и `setup.py`.

## 🚀 Основные возможности

- Генерация красивых QR-кодов (в форматах PNG, SVG, PDF) для быстрой делёжки ссылками.
- Сканирование QR-кодов

## 🛠️ Стек технологий
- **Язык:** Python 3.10+
- **Библиотеки:** `segno` + `Pillow` (генерация QR), `plyer` (выбор файлов), `colorama`.

## 💻 Инструкция по установке и запуску

### 1. Подготовка системы (Важно для QR)
Проект использует библиотеку `pyzbar`/`segno`. Для её корректной работы в системе должен быть установлен графический движок:
- **Windows:** Установите официальный пакет [ZBar](http://sourceforge.net).
- **Linux (Ubuntu/Debian):** `sudo apt-get install libzbar0`
- **macOS:** `brew install zbar`

### 2. Клонирование репозитория
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd Quick-Response-code
```

### 3. Настройка окружения и установка
Проект использует современный стандарт настройки `pyproject.toml`.

**Для Windows:**
```bash
# Создаем виртуальное окружение
python -m venv .venv

# Активируем его
.venv\Scripts\activate

# Устанавливаем проект и все его зависимости
pip install .
```

**Для Linux / macOS:**
```bash
python -m venv .venv
source .venv/bin/activate
pip install .
```

### 4. Настройка конфигурации
1. Создайте файл конфигурации (или укажите токен в коде).
2. Запустите бота:
```bash
python main.py
```
